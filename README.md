# 내 작업대

일정, 할 일, 메모, 바로가기를 한 곳에 모으는 개인용 웹 앱입니다. 브라우저에서 열고 "앱으로 설치"하면 컴퓨터와 폰에서 독립 앱처럼 쓸 수 있습니다.

## 데이터는 어디에 저장되나요

이 저장소에는 **앱 코드만** 있습니다. 일정과 메모는 사용자가 따로 만든 **비공개 저장소**의 `data.json` 파일에 저장됩니다. 앱은 GitHub API로 그 파일을 읽고 씁니다.

- 비공개 저장소가 아니면 앱이 연결을 거부합니다.
- 접근 열쇠(fine-grained personal access token)는 기기의 브라우저 `localStorage`에만 저장됩니다. 이 저장소의 코드에는 열쇠도 계정 정보도 들어 있지 않습니다.
- 두 기기에서 같은 파일을 고치면 항목 단위로 합칩니다. 같은 항목을 동시에 고친 경우에는 나중에 저장한 쪽이 남습니다.

## 처음 연결하기

1. 데이터를 담을 **비공개** 저장소를 하나 만듭니다. README만 있어도 됩니다.
2. GitHub 설정의 개인 액세스 토큰(세분화된 토큰)에서 열쇠를 만듭니다.
   - Repository access: Only select repositories, 위 데이터 저장소 하나만 선택
   - Repository permissions: Contents를 Read and write로 설정
3. 앱을 열고 `계정/저장소이름`과 열쇠를 붙여 넣습니다. 기기마다 한 번씩 합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면과 동기화 로직 전체 |
| `sw.js` | 앱 파일을 기기에 저장해 인터넷 없이도 열리게 하는 서비스 워커 |
| `manifest.webmanifest` | 앱 설치 정보 |
| `*.png` | 앱 아이콘 |

## 한계

- 실시간 동기화는 아닙니다. 앱을 열 때, 화면으로 돌아올 때, 1분마다, 상태 표시를 눌렀을 때 맞춥니다.
- `data.json` 하나에 모두 저장하므로 약 1MB가 넘으면 느려집니다. 오래된 항목을 정리해 주세요.
